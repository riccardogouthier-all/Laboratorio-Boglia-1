Altro dispositivo:

source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt

Note:

pip freeze include anche dipendenze transitive → lista lunga ma riproducibile. Alternativa: scrivere a mano solo pacchetti diretti.
Versione Python: annotarla (README o .python-version), stessa major.minor.
Dipendenze native (es. psycopg2, numpy su arch diverse) possono richiedere pacchetti di sistema.
Tool più robusti: pip-tools, poetry, uv (lockfile).
